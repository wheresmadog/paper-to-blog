# Project rules

## Skill testing

For a fresh-session skill test, provide only the skill invocation and the paper locator (arXiv URL or local PDF path). Do not add descriptions, test context, output names or paths, layout preferences, workflow instructions, or reporting requirements. Let the skill supply its own defaults and instructions.

Example test prompt:

```text
/paper-to-blog:paper-to-poster https://arxiv.org/abs/2603.14363
```
